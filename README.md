# ⚡ Интерактивная карта ГЭС

Интерактивная карта крупных гидроэлектростанций России: рельеф, климат, гидрология, катастрофические сценарии.

## Возможности

- **10 ГЭС России**: Волжская, Жигулёвская, Саратовская, Чебоксарская, Нижегородская, Воткинская, Камская, Саяно-Шушенская, Красноярская, Братская
- **Режимы**: 📜 история (реальные данные с 2023 г.), 🌤 прогноз (±период), 🌍 климат (модель до 2030 г.)
- **Сценарии**: норма, 🌊 паводок, ☀️ засуха, 💥 прорыв плотины (анимация волны по реальному руслу из OSM)
- **Реальные контуры водохранилищ** из OpenStreetMap (встроены в `reservoirs-data.js`, работают офлайн)
- Данные: Open-Meteo API (температура, осадки, расход реки), Overpass API (русла); офлайн-режим с кэшем
- Графики мощности/уровня (Chart.js), таймлайн, PWA-обвязка (service worker)

## Запуск

Это статический сайт — достаточно любого веб-сервера:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
Сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка, подключение Leaflet/Chart.js |
| `app.js` | логика карты, модель ГЭС, сценарии |
| `style.css` | стили |
| `reservoirs-data.js` | реальные контуры водохранилищ (снимок OSM, упрощённые полигоны) |
| `sw.js` | service worker (кэширование, офлайн) |
