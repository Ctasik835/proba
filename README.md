# ⚡ Интерактивная карта ГЭС

Интерактивная карта крупных гидроэлектростанций России: рельеф, климат, гидрология, катастрофические сценарии. Картография — **Яндекс.Карты API 2.1** (подложки: Яндекс-схема, спутник, гибрид, OSM, OpenTopoMap).

> ℹ️ Для рендера карты используется ключ API Яндекс.Карт в `index.html`. Свой ключ (бесплатно) можно получить на https://developer.tech.yandex.ru/services/ (тариф «API Карт»).

## Возможности

- **3 новые ГТС Северного Кавказа**: Гизельдонская ГЭС (р. Гизельдон, 22,8 МВт), Гунибская ГЭС им. Расула Гамзатова (р. Каракойсу, 15 МВт, арочная плотина 73,3 м), Баксанская ГЭС (р. Баксан, 27 МВт)
- **Режимы**: 📜 история (реальные данные с 2023 г.), 🌤 прогноз (±период), 🌍 климат (модель до 2030 г.)
- **Сценарии**: норма, 🌊 паводок (водохранилище краснеет и разливается), ☀️ засуха (жёлтый, вода отступает), 💥 прорыв плотины (расчёт по реальным гидравлическим формулам + зона затопления)
- **Физика прорыва плотины**: одномерные уравнения мелкой воды (Сен-Венана) вдоль реального русла: схема Годунова с потоком Гуно (HLL), шаг по условию Куранта, трение Мэннинга n=0,04, корректная обработка сухого дна. Профиль дна — реальный (DEM, `terrain-data.js`). Проран моделируется водосливом широкого порога Q = 1,7·B·H^1,5 с опорожнением фактического объёма водохранилища за ~20 мин; ширина затопления по ячейкам — из рассчитанных глубин. Волна, скорость фронта и охват — результат расчёта, а не анимационная условность
- **Водные объекты**: Гизельдонское вдхр — 10,81 км² (проектные данные, контур морфится норма/засуха/паводок); Гунибское — реальный контур OSM, приведён к зеркалу 0,6 км² при НПУ; у Баксанской ГЭС вместо водохранилища отрисован **деривационный канал** (~10 км, реальная трасса из OSM, включая тоннели)
- **Русла** Гизельдона→Ардона, Каракойсу→Аварского Койсу, Баксана→Малки встроены в `rivers-data.js` (офлайн)
- Данные: Open-Meteo API (температура, осадки, расход реки), Overpass API (русла); офлайн-режим с кэшем
- Графики мощности/уровня (Chart.js), таймлайн, PWA-обвязка (service worker)

## Запуск

Это статический сайт — достаточно любого веб-сервера:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
Сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка, подключение Leaflet/Chart.js |
| `app.js` | логика карты, модель ГЭС, сценарии |
| `style.css` | стили |
| `reservoirs-data.js` | реальные контуры водохранилищ (снимок OSM, упрощённые полигоны) |
| `rivers-data.js` | центрлинии русел ниже плотин (OSM, офлайн-снимок) |
| `terrain-data.js` | профиль дна русла (DEM-отметки Open-Meteo/SRTM) для расчёта прорыва |
| `sw.js` | service worker (кэширование, офлайн; v13) |
